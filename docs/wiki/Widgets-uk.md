# Віджети

Віджети стоять нагорі панелі; клацніть один, щоб відкрити його вікно. Порядок - ▲ ▼ або перетягування; око у списку ховає віджет з панелі (на робочому столі його можна лишити).

| Віджет | Що робить |
|---|---|
| **Час і дата** | Годинник, календар, державні свята (з date.nager.at) і всесвітні дні, власні дати, будильники, таймери, секундомір, годинники на робочому столі (цифровий, аналоговий, з календарем). Точність годинника можна звірити з сервером часу. |
| **Погода** | Поточна погода, прогноз на години й тиждень, теми погоди, європейські чи американські одиниці. |
| **Монітор системи** | CPU, GPU, ОЗП із графіками; характеристики; «Завдання» - процеси й служби; «Аналіз» - навантаження процесу (чи групи з дочірніми) протягом часу; «Історія» - температури й навантаження за добу. Температури можна вивести в трей. |
| **Мережа** | Швидкість завантаження й віддачі, пінг, адаптери, Wi-Fi, перемикач брандмауера. |
| **Простір** | Диски з вільним місцем; стан (SMART) і обслуговування; форматування; відновлення файлів. |
| **Батарея** | Заряд і стан живлення (лише на пристроях з батареєю). |
| **Нотатки** | Нотатки на робочому столі; їх можна закріпити й зберегти у файл (.txt чи .rtf - меню заголовка). |
| **Палітра** | Піпетка, колірні моделі (HEX та інші), зразки, один клік копіює HEX. |
| **Кубик** | d4-d20, кілька кубиків разом, власні назви граней, історія. |
| **QR-код** | Текст, посилання, Wi-Fi, контакт, e-mail, SMS, телефон, місце; рівень виправлення помилок; логотип у центрі; збереження в PNG чи SVG. |
| **Безпека** | Перевіряє процеси, автозапуск, служби й налаштування. Див. [[Tools-uk]]. |
| **Шифрування** | Шифрування тексту й файлів, хеші. |
| **Очищення** | Очищення сміття Windows. |
| **Відновлення** | Відновлення видалених файлів і тек з диска чи флешки. |

## Віджети на робочому столі

Більшість віджетів можна поставити на робочий стіл (кнопка з екраном у вікні віджета). Віджет перетягується мишею, розмір - за куток; розмір має межі, тож дрібні підписи завжди читаються. Замок закріплює віджет (кліки проходять до робочого столу), повзунок задає прозорість. Великі написи (час, температура, підсумок) - шрифтом нотаток для теми; вимкнути: Налаштування → Вигляд → «Шрифт нотаток у віджетах на столі».

## Аналіз процесу (Монітор системи → «Аналіз»)

Виберіть процес у «Завданнях» і натисніть **«Аналіз»**. Посередині з'явиться вікно: як часто заміряти (0,5-10 с) і куди писати журнал, далі **«Почати запис»**. Під час запису видно живий графік, потім - програвач: тягніть по графіку або натисніть відтворення (швидкість - повзунком, ×1 - ×600), а таблиця покаже значення в цей момент і мінімум, максимум, середнє та 95-й процентиль для кожного показника. Що саме ви бачите, показує рядок програвача: кнопка **«Наживо»** з червоним тлом і крапкою, що блимає, - запис іде й графік рухається; звичайна кнопка з червоним кружечком і напис «перегляд запису» - ви відмотали назад (клік повертає наживо); коли запис не йде - напис «Запис завершено» чи «Збережений журнал».

Показники (підказка на кожному пояснює його простими словами):

| Показник | Що означає |
|---|---|
| **ЦП** | частка всього процесора (усіх ядер), яку займає процес |
| **ГП** | навантаження відеокарти цим процесом, як у Диспетчері завдань |
| **Відеопам'ять** | пам'ять відеокарти, зайнята процесом |
| **ОЗП** | оперативна пам'ять, яку процес займає просто зараз |
| **Виділена** | пам'ять, яку процес замовив лише для себе (разом із файлом підкачки); постійне зростання - витік пам'яті |
| **Читання / Запис** | скільки даних за секунду процес читає й записує (диски, мережа, пристрої) |
| **Дескриптори** | відкриті файли, ключі реєстру, потоки; постійне зростання - витік |
| **GDI / USER** | об'єкти малювання й вікна; Windows дозволяє до 10 000 на процес |

Кожен замір одразу дописується в журнал CSV (відкривається в Excel), підсумок - поруч у .txt. Запис триває й після закриття вікна монітора і зупиняється сам, коли процес завершиться. «Відкрити журнал…» програє давніший запис; стрілки ‹ › гортають журнали в тій самій теці, кошик видаляє показаний журнал разом із підсумком (у Кошик Windows), хрестик прибирає результати з вікна (файли лишаються).

Наведіть мишу на графік - підкажеться точне значення й час. Мінімум і максимум позначено, якщо лінія справді змінюється (нульовий мінімум не позначається). Старі журнали видаляються самі - за загальним налаштуванням **Налаштування → Діагностика → Зберігання журналів**; там само кнопки «Відкрити» й «Очистити» для всіх записів аналізу.

**Група процесів.** Перемикач «Разом із дочірніми процесами» у вікні нового запису підсумовує процес і все, що він запустив (вкладки браузера, лаунчер і гру); нові дочірні додаються самі, запис іде, поки живий хоч один процес групи. Критичні сповіщення під час запису позначаються на графіку червоною рискою (наведіть мишу - що сталося) і потрапляють у підсумок .txt.

## Нагляд за системою (Налаштування → Панель)

Раз на 5 секунд NeoBar стежить за датчиками (дешево - те саме спільне опитування, що й для віджетів):

- **Критичні сповіщення** - перегрів процесора чи відеокарти (межі налаштовуються, типово 95 і 90 °C), відеопам'ять зайнята понад межу (типово 95 %), оперативна пам'ять понад 95 % (з переліком, хто найбільше займає), один процес займає забагато пам'яті (типово - половину всієї). Умова має триматися ~15 с, те саме сповіщення - не частіше ніж раз на 10 хв. Кожне пишеться в **журнал сповіщень** (`logs\alerts.log`), в історію і позначкою в запис аналізу процесу, якщо той іде.
- **Історія за добу** - щохвилини найвища температура й середнє навантаження процесора, відеокарти, пам'яті й відеопам'яті; зберігається в `history.csv` поруч із програмою. Видно в **Моніторі системи → «Історія»** разом із подіями: сповіщеннями NeoBar і знахідками журналу Windows (зависання відеодрайвера, нестача пам'яті, раптове вимкнення). Перевірка системи цим пояснює збої: чи була відеокарта гаряча в момент зависання драйвера, чи навантаження було на межі перед раптовим вимкненням.
- **Звіт після гри** - для ігор довших за 2 хвилини: FPS (середній, 1 % low, найнижчий - якщо для гри ввімкнено оверлей), температури й навантаження, сповіщення під час гри. Приходить сповіщенням, повний звіт - у `Документи\NeoBar\Ігри`.

## Місце й погода (Налаштування → Місце й погода)

NeoBar може визначити місцезнаходження службою розташування Windows або, якщо вона вимкнена, за IP-адресою (точність до міста). Без дозволу місто задається вручну: введіть 3+ літери або клацніть на карті (OpenStreetMap). Часовий пояс може слідувати за місцем. Завантажені дані (погода, свята, плитки карти, значки) кешуються; без інтернету показуються збережені.
