# Встановлення

Завантажте останні файли зі сторінки [Releases](https://github.com/NeoCyberin/NeoBar/releases):

- `NeoBar-x.y.z-setup.exe` - встановлювач. Права адміністратора не потрібні, встановлюється для поточного користувача.
- `NeoBar-x.y.z-portable.zip` - портативна версія. Розпакуйте **весь архів** у будь-яку теку з правом запису й запустіть `NeoBar.exe`. Профілі й налаштування зберігаються поруч з exe.
- `SHA256SUMS.txt` - контрольні суми для перевірки завантажених файлів.

Вимоги: Windows 10 або 11 (64- чи 32-бітна) і .NET Framework 4.x, який уже є у Windows.

## Перший запуск

З'явиться вікно **Швидке налаштування**: край екрана, поведінка (закріплена чи автосховок), тема, віджети нагорі панелі, а також чи запускати разом з Windows, вмикати оверлей у іграх і визначати місцезнаходження. Усе можна змінити потім у налаштуваннях.

## SmartScreen

Нова програма може викликати попередження «Windows захистила ваш ПК». Перевірте підпис файла (Властивості → Цифрові підписи), потім **Докладніше → Все одно виконати**. Див. [[FAQ-uk]].

## Видалення

Скористайтеся програмою видалення встановлювача, а портативну версію просто видаліть. `NeoBar.exe --uninstall` прибирає сліди, які NeoBar залишив у системі (автозапуск тощо).
