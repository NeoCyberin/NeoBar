# Переклад

1. У NeoBar: Налаштування → Вигляд → **Створити шаблон**. Поруч з `NeoBar.exe` з'явиться `lang\template.lang` - усі тексти українською й англійська підказка над кожним.
2. Скопіюйте його як `lang\<код>.lang` (наприклад `nl.lang`) і задайте на початку `@name`, `@code`, `@flag` та `@quotes`:
   - `@flag h #FFFFFF #888888` - горизонтальні смуги згори вниз (`v` - вертикальні), кольори `#RRGGBB`;
   - `@quotes « »` - лапки вашої мови; `«»` у текстах замінюються на них.
3. Впишіть переклад після кожного рядка `>`. Порожні рядки показуються англійською. Зберігайте `\n`, `{0}` і символи на кшталт `•` та `%`.
4. Перезапустіть NeoBar і оберіть мову в налаштуваннях.
5. Щоб додати переклад у NeoBar, покладіть файл у `res/lang/` і відкрийте pull request; `build.bat` вбудовує кожен файл із цієї теки.

Літери з діакритикою підтримуються вбудованими шрифтами для мов на латиниці.
