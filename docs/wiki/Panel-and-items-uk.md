# Панель і елементи

## Положення й поведінка (Налаштування → Панель)

- **Край екрана:** ліворуч, праворуч, угорі чи внизу, на будь-якому моніторі. Ширина лівої/правої панелі: 56-240 px.
- **Закріплена:** інші вікна підлаштовуються під панель. **Автосховок:** панель лежить над вікнами й з'являється, коли миша доходить до краю. Опція *компактна панель* (за розміром вмісту, по центру, закруглена) - для верхньої/нижньої панелі в режимі автосховку.
- **Ігри та програми на весь екран:** панель ховається, пошук вимикається, усе інше ставиться на паузу; працює лише оверлей гри.
- Запуск з Windows; завжди від імені адміністратора (без запиту UAC при старті).

## Елементи (Налаштування → Елементи)

Програми, теки, сайти, групи, роздільники й віджети. Додавайте кнопками під списком або **перетягніть ярлик, теку чи посилання на панель**. *Ярлики…* бере їх з робочого столу, *Система…* додає Цей ПК, Кошик, теки користувача й параметри Windows.

- **Порядок:** кнопки ▲ ▼ або перетягування. Віджети завжди лишаються на початку панелі.
- **Значок:** автоматично (з файла чи теки), у стилі теми, завантажений один раз із сайту або власний файл (.ico, .png, .jpg, .bmp, .exe, .dll).
- **Групи:** заголовок з елементами під ним - розгорнуті або компактна плитка 2×2 з мініатюрами; кожна група може мати свій колір.
- **Теги пошуку:** слова через кому, щоб легше знайти елемент.

## Вигляд (Налаштування → Вигляд)

Розмір значків 24-96 px, підписи знизу/зверху/без них, ефект при наведенні (збільшення, підйом, сяйво), плавні анімації, шрифт підписів, тема. Див. [[Wallpapers-and-themes-uk]].

## Пошук

Поле пошуку на панелі й глобальна гаряча клавіша (Налаштування → Пошук). Вкладка *Комп'ютер* шукає всі файли й теки: індекс NTFS, коли NeoBar запущено від адміністратора, інакше - Windows Search. NeoBar також може підказувати програми й ігри, яких ще немає на панелі.

## Профілі

Кожен профіль має свої елементи, налаштування, нотатки, список ігор і тему. Профіль можна захистити PIN-кодом (видалення теж питає PIN). Налаштування → Дані: експорт профілю у файл `.nbpack`, імпорт або скидання до типових (стара копія лишається як `neobar.ini.bak`).
